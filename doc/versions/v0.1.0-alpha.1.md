# KireiBox 0.1.0-alpha.1

## Background

First independent KireiBox foundation build. This version keeps the current
RinneMobile Compose launcher and four-engine bridge while changing the
installable identity to `com.kireibox.app`.

- debug device: Pixel_8, `emulator-5554`, Android 17/API 37, x86_64

## Database/API

KireiBox uses its own database files and does not read RinneMobile data. The
metadata controller uses YukiHub's source keys and `yukihub_prefs`, including
`metadata_source`, `visible_metadata_source_<gameId>` and `bangumi_token`.
The selected source is stored independently for VNDB, Bangumi, Bangumi镜像,
月幕Gal and Hikarinagi. Manual cover confirmation is downloaded only after
selection.

The Compose settings page exposes YukiHub KRKR options: engine version, startup
compatibility mode, independent KRKR save directory, Artemis save directory and
the native KRKR entry. The four engine launch bridge and Android package target
remain available.
