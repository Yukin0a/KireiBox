# KireiBox 0.3.0-alpha.2

## Changes

- Replaced the fan control with a purple chevron whose edit and appearance
  actions expand horizontally to the left. The title block is measured at
  runtime, leaving only 8dp compact / 11dp wide spacing before the dashboard.
- Upgraded dashboard JSON to version 2 with auto-fill, manual grid coordinates,
  persistent holes, new widget sizes, style variants and a 7/30-day play trend.
- Reworked Recent Games so its outer area follows the active theme while each
  game remains an independent horizontal card strip.
- Added whole-card drag editing, transparent style/resize controls, a floating
  add button, an auto-fill toggle, wiggle/delete/resize motion and reduced-mode
  fallbacks.
- Cards publish first with per-engine KireiBox covers. A bounded two-worker
  pipeline then tries at most three cleaned title queries, automatically saves
  high-confidence results and marks low-confidence/network results for review.
- Applied the supplied pink chibi image to legacy/adaptive launcher icons and
  pre-Android 12/Android 12+ splash screens.
- Version is 0.3.0-alpha.2 / versionCode 5. Database schema remains v18.

## Architecture share

Measured over 12,666 nonblank Kotlin/Java lines in `:app` and
`:core-yukihub`, excluding the four native engine implementations:

| Layer | Lines | Share |
|---|---:|---:|
| KireiBox UI and shell | 4,598 | 36.3% |
| Four-engine launch glue | 2,590 | 20.4% |
| YukiHub data/scanner/metadata/settings core | 5,478 | 43.3% |

Within the non-UI lower layer, YukiHub core is 67.9% and launch glue is 32.1%.
RinneMobile remains an interaction reference only: there is no Rinne module,
database, scanner, cover queue or artifact in the runtime graph.

## Rollback

Install the preserved 0.3.0-alpha.1 APK. Database schema remains v18. The old
version ignores dashboard-v2-only fields and can fall back to its default
dashboard without modifying game records.

  passed. Debug/Release ran 162 JVM tests with 0 failures, 0 errors and 0
  skipped. Lint reports 0 errors and 313 inherited warnings.
- JVM coverage includes dashboard v1→v2 migration, damaged JSON repair,
  manual holes/collisions/priority placement, staged title cleaning and 7/30
  day play-trend aggregation.
- Pixel 8 API 37 x86_64 emulator with ARM translation validated the Release at

  (360×640dp), 1536×2048 @320dpi (768×1024dp) and 2048×1536 @320dpi
  (1024×768dp).
- UI checks covered the horizontal chevron menu, measured top gap, themed
  Recent Games strips, editor controls, compact ring text, bottom scroll
  clearance, wide four-column layout and floating Dock.
- ATRI launched through `com.akira.tyranoemu.remote.Kirikiroid139`; its
  `:kirikiri2` process and activity remained alive for 65 seconds with no
  fatal exception, native abort, patch error or `KrFontScaleManager` log.
- Final Release cold start completed in 1,360 ms on the emulator.
- APK checks passed arm64-only ABI, zip alignment, Signature Scheme v2 and
  `sf.sf2` exclusion. Physical Pixel 8, Android 14 and HarmonyOS 2 hardware
