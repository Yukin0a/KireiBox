# KireiBox 0.2.0-alpha.3

## Background

This iteration aligns the KireiBox Compose presentation with the confirmed
RinneMobile visual reference while retaining the YukiHub runtime and database.

## Changes

- The Home statistics card now opens a continuous `库内 N 部游戏` Action
  Sheet with recent-play and play-time sorting. Selecting a row closes the
  ranking and opens the existing per-game Action Sheet.
- Home, recent-list and library launch controls share one solid circular
  button: light purple with a dark triangle in dark mode, deep purple with a
  white triangle in light mode.
- Core Compose UI no longer bypasses the shared AppleTypography scale with raw
  font sizes. Text chevrons were replaced by vector icons; no font file was
  added to the APK.
- Compose prompts cache their displayed content through a 180 ms fade/scale
  entrance and 140 ms exit. Reduced motion uses an 80 ms fade only. The scrim
  is lighter and no longer turns the Dock into a black block.
- The Dock is an inset-aware floating sibling over the Haze-backed page rather
  than a `Scaffold.bottomBar`. Home, library and settings use the measured
  navigation inset plus 106dp of scroll clearance.
- No database, scanner, cover-state, engine, or public Yuki API changes.

## Rollback

Install the preserved alpha.2 APK. Database schema remains v18, so no data
migration or rollback transform is required.

## Tests

- `gradlew.bat test :app:lintDebug :app:assembleRelease`: passed.
- JVM: 126 tests across Debug/Release suites, 0 failures, 0 errors, 0 skipped.
  New tests cover both ranking orders, compact minute/hour formatting and Dock
  clearance under different navigation insets.
- Lint: 0 errors, 309 inherited warnings. Release lint-vital, R8/resource
  shrinking and native arm64-v8a CMake build passed.
- Pixel 8 API 37 x86_64 emulator with ARM translation: final Release installed;
  cold start completed in 966 ms. The purple button launched ATRI through
  `com.akira.tyranoemu.remote.Kirikiroid139`; the main and engine processes
  remained alive for 60 seconds with no fatal exception, native abort, patch
  error or `KrFontScaleManager` line in filtered logcat.
- Visual QA covered 1080x2400 at 420dpi, 1080x1920 at 480dpi (360x640dp),
  1032x2237 at 420dpi (393x852dp), 1536x2048 at 320dpi (768x1024dp),
  2048x1536 at 320dpi (1024x768dp), and 2560x1600 at 320dpi (1280x800dp).
  Ranking-to-game navigation, two-column phone policy, wide two-pane home,
  light/dark launch colors, prompt entry/exit paths, and settings scrolling
  above the Dock were checked.
- Physical Pixel 8, Android 14 and HarmonyOS 2 hardware remain unverified.
