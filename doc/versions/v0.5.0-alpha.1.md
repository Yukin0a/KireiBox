# KireiBox 0.5.0-alpha.1

## Changes

- KRKR game cards now expose an explicit XP3 launch-target picker beneath the
  launch action. The selected relative path is persisted without moving or
  renaming game files.
- KRKR always saves to each game's own `savedata` directory. Startup performs a
  real write/fsync/rename/delete probe and safely copies missing files from
  retired private save locations without overwriting conflicts.
- Installed Android launchable activities are selected in-app through
  PackageManager; this does not require storage permission.
- KRKR, ONScripter, Tyrano and Artemis use process-owned monotonic foreground
  journals. Android app cards record a successful launch count only.
- Dashboard spotlight JSON v4 adds recent, favorites, all-library and fixed-game
  sources with ordered, per-process random and daily-random strategies.
- Library search uses cached metadata titles and aliases. Seven-day charts use
  labelled bars; 30-day charts use a labelled area graph.
- Cover work is bounded to three concurrent searches and two concurrent
  downloads. Source selection explains public access and Token requirements.
- Settings adds opt-in diagnostics plus redacted copy/export log actions.
- Removed unreferenced RPGMaker hooks and excluded historical SoundFont/Bugly
  residues; cover bitmap cache is capped at 16 MiB.
- Version is 0.5.0-alpha.1 / versionCode 7.

## Rollback

The preserved 0.4.0-alpha.1 APK remains available in `apk/`. Dashboard v4
configuration is preference-only; a prior build will fall back to its default
dashboard if it cannot parse a newer layout. Legacy KRKR save sources are
retained after copy-back, and conflicts are never overwritten. Back up app and
game data before downgrading an alpha build.

## Tests

- `gradlew test`: 100 Debug and 100 Release test executions, 0 failures,
  0 errors and 0 skipped.
- `:app:lintDebug`: 0 errors and 319 inherited warnings.
- Debug and Release builds complete successfully.
- Pixel 8 AVD (API 37, 1080 x 2400) verifies the library Add Game sheet,
  PackageManager Android-app list, KRKR XP3 picker, settings diagnostics,
  statistics charts and dashboard controls.
- The final Release APK launches ATRI through Kirikiroid139. Runtime logs verify
  that KRKR uses `/storage/emulated/0/Download/gal/ATRI/savedata/` and completes
  real write, rename and delete operations in that game-local directory.
- Force-stopping KRKR and reopening KireiBox returns to `LauncherActivity`
  without a fatal Android runtime exception.
- Package audit confirms arm64-v8a only, three required KRKR compatibility
  variants and three Artemis variants. `sf.sf2`, Bugly, old KRKR duplicate
  libraries and removed RPGMaker hook assets are absent.

## Limits

- KRKR was runtime-tested with ATRI on the Pixel 8 AVD. ONScripter, Tyrano and
  Artemis timing journals are covered by unit/build checks but still need
  representative real-game runtime tests.
- The AVD host is x86_64 with Android's arm64 bridge. Huawei/HarmonyOS and a
  physical arm64 device still require device acceptance testing, especially
  removable-SD and restricted `Android/data` paths.
- The artifact uses the configured Android debug certificate fallback. It is
  suitable for installation testing, not Play Store production signing.
