# KireiBox 0.3.0-alpha.1

## Background

This version introduces a user-editable Home dashboard and completes the
favorite-first, motion-aware Apple-style library interaction. Game data,
settings and removal continue to use YukiHub; RinneMobile remains a visual and
motion reference only.

## Changes

- Favorites lead all three library sort modes and use title/ID stable
  fallbacks. Favorite cards show a safe-inset red heart badge, while library
  cards no longer expose a direct launch button.
- Long-press editing retains non-destructive `hidden=true` removal and a
  five-second undo. Polished mode uses the Rinne-style `±0.7° / 125 ms` jiggle,
  180 ms removal and spring grid reflow; Reduced mode uses a short fade.
- The legacy reduced-motion boolean is migrated to Auto/Polished/Reduced.
  Auto resolves from system animator state, low-RAM classification, memory
  class and power saver, while preserving the legacy mirror for rollback.
- The Home appearance control is now a triangle hub whose edit and theme
  actions fan outward. A touch-layer defect found during emulator QA was fixed
  so the visible fan actions remain above the tap-away scrim.
- Home is a versioned dashboard with independent two-column compact and
  four-column wide profiles. Widgets support draft-only add/remove/reorder,
  legal-size snapping, game rebinding and explicit save/discard. Layout JSON is
  normalized to 12 widgets and safely falls back on malformed data.
- Compact defaults remain a `2×2` game display, `2×1` overview and `2×1`
  recent list. Wide defaults use a `2×2` game display with two `2×1` widgets.
  Hidden games disappear from normal Home but stay rebindable in the editor.
- Version is `0.3.0-alpha.1` / versionCode 4. Database schema remains v18.

## Rollback

Install the preserved 0.2.0-alpha.3 APK. Database schema remains v18. Older
versions ignore the new dashboard and motion-mode preference keys; the legacy
reduced-motion mirror is maintained.
